 ♔ Шахматный тренажер - WPF Клиент

Шахматный тренажер - это десктопное приложение для Windows, которое позволяет играть в шахматы в двух режимах: против друга на одном компьютере или против искусственного интеллекта (Stockfish). Приложение имеет систему пользователей, рейтинг, статистику и красивый современный интерфейс.

 ✨ Возможности

 🎮 Игровые режимы
- 🤖 Режим VS ИИ - игра против компьютера (Stockfish) с разными уровнями сложности
- 👤 Режим VS ЧЕЛОВЕК - игра с другом за одним компьютером (передача хода)

 👤 Система пользователей
- Регистрация нового аккаунта
- Вход в существующий аккаунт
- Профиль пользователя с аватаром
- Отображение ника и рейтинга в шапке приложения

 📊 Рейтинговая система
- Начальный рейтинг: 1200
- +15 рейтинга за победу
- -10 рейтинга за поражение
- Рейтинг не меняется при ничьей
- Автоматическое обновление после каждой игры

 🏁 Игровой процесс
- Визуальная подсветка возможных ходов при выборе фигуры
- Зеленая подсветка выбранной фигуры
- Индикатор текущего игрока (БЕЛЫЕ/ЧЕРНЫЕ)
- История ходов сбоку
- Таймеры на партию (по 10 минут каждому игроку)
- Анимация перемещения фигур
- Звуковые эффекты при ходе

 📈 Статистика
- Количество сделанных ходов
- Время игры
- Просмотр статистики после игры
- История всех сыгранных партий

 🎨 Интерфейс
- Современный темный дизайн
- Классическая шахматная доска с буквами и цифрами
- Адаптивный размер доски
- Индикатор "ИИ думает" во время хода компьютера
- Уведомления о начале игры

 🛠 Технологии

- .NET 6.0 - платформа разработки
- WPF (Windows Presentation Foundation) - технология создания интерфейса
- MVVM паттерн - архитектурный паттерн
- Entity Framework Core - работа с данными
- ChessDotNet - библиотека для шахматной логики
- PostgreSQL - база данных (через API)

 🚀 Установка и запуск

 Системные требования
- Windows 10 или новее
- Visual Studio 2022 (Community Edition достаточно)
- .NET 6.0 SDK
- PostgreSQL (для API, необязательно для клиента)

🎯 Использование
Первый запуск
1.	При первом запуске приложение попытается подключиться к API
2.	Если API недоступен, появится предупреждение (игра будет работать в локальном режиме)
Вход в систему
1.	На экране входа введите username и password
2.	Или создайте новый аккаунт через "Регистрация"
3.	После входа вы попадете на главный экран игры
Выбор режима игры
В правом верхнем углу находится переключатель:
•	🤖 VS ИИ - игра против компьютера
•	👤 VS ЧЕЛОВЕК - игра с другом
Начало игры
1.	Нажмите кнопку "♛ НОВАЯ ИГРА"
2.	Подтвердите начало игры
3.	Доска инициализируется, запустятся таймеры
Как ходить
•	Кликните на фигуру - подсветятся возможные ходы
•	Кликните на подсвеченную клетку - фигура переместится
•	В режиме VS ИИ компьютер ответит автоматически
Сдача
•	Если позиция проигрышная, нажмите "⚑ СДАТЬСЯ"
•	Поражение принесет -10 рейтинга
Завершение игры
•	После мата, пата или сдачи появится панель с результатом
•	Можно посмотреть статистику или начать новую игру

❗ Возможные проблемы и решения
Не подключается к API
Симптомы:
•	При запуске предупреждение "Сервер недоступен"
•	В режиме VS ИИ фигуры не двигаются
Решение:
1.	Проверьте, запущен ли API сервер
2.	Убедитесь, что URL в ApiService.cs правильный
3.	Проверьте, что порты (7259) не заблокированы брандмауэром
4.	Временно отключите антивирус для теста
Фигуры не двигаются в режиме VS ИИ
Симптомы:
•	Ход отправляется, но фигуры остаются на месте
•	В консоли API видны запросы
Решение:
1.	Проверьте логи API на наличие ошибок
2.	Убедитесь, что Stockfish.exe находится в папке Engines API
3.	Проверьте, что в GameManager.cs вызывается OnPropertyChanged(nameof(Board))
Неправильный цвет при игре с другом
Симптомы:
•	После хода не переключается игрок
•	Можно ходить два раза подряд
Решение:
•	Проверьте, что в GameManager.MakeMoveLocal() правильно переключается CurrentPlayer
